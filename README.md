# 求职投递追踪器

一个无需登录、无需后端的个人求职投递管理页面。数据只保存在当前浏览器的 `localStorage` 中。

## 功能
- 输入公司网址后，本地推断可编辑的公司名称
- 岗位手动输入，投递情况使用标签选择
- 新增记录自动填写当地当天日期
- 公司官网与具体岗位链接分别保存
- 新增、编辑和删除投递记录
- 搜索、状态筛选和日期排序
- 投递进度统计
- JSON 备份导入与导出
- 手机和桌面端响应式布局

## 使用
直接打开 `index.html`，或在项目目录运行：
```bash
python -m http.server 8000
```
然后访问 <http://localhost:8000>。

## 数据说明
清除浏览器站点数据会删除记录，请定期使用“导出备份”。本站不会上传任何投递信息。
